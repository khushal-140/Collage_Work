## Getting started

Most Python exercises can be opened and run locally:

1. Clone the repository.
2. Install Python 3.
3. Install the libraries used by an exercise, for example:

   ```bash
   pip install pandas numpy jupyter
   ```

4. Open a Python file with your editor, or start Jupyter for the notebook:

   ```bash
   jupyter notebook
   ```

5. Keep the included CSV, Excel, JSON, and database files in their original locations so scripts can find their data.
